# Codebook การจำแนกเจตนา (Intent Classification Codebook)

เวอร์ชัน: v4 · อัปเดต: 2026-08-17

โดเมนข้อมูล: ข้อความ social media ภาษาไทย (WiseSight sentiment dataset), ภาษาพูด คำถิ่น คำแชท สะกดเพี้ยน อีโมจิ แฮชแท็ก ปนกัน

7 คลาส: Miscellaneous · Sarcasm · Request · Question · Recommendation · Expression · Assertion

ไฟล์นี้เป็นฉบับอ่านสำหรับมนุษย์
prompt ที่ส่งเข้า LLM จริงอยู่ที่ `prompt/system_prompt.txt` (prompt version `tree_v4`, hash `47a0621bd3da`)
ซึ่งเขียนให้สั้นเพื่อประหยัด token, เนื้อกฎเหมือนกันทุกข้อ แต่ถ้อยคำต่างกัน

## 1. หลักการ

จำแนกจาก เจตนาหลัก ของผู้เขียน ไม่ใช่รูปประโยคหรือคำสำคัญเพียงอย่างเดียว โดยไล่ตรวจตามลำดับข้อ 0 → 6 เข้าเงื่อนไขข้อไหนก่อน ให้ตัดสินที่ข้อนั้นทันทีและหยุด ห้ามข้ามลำดับหรือเลือกจากความรู้สึกโดยรวม

ก่อนตัดสินทุกครั้ง ให้ แปลงคำถิ่น/คำแชท/สะกดเพี้ยน/เสียงยืดเป็นรูปมาตรฐานก่อน:

| รูปที่พบ | แปลงเป็น |
|---|---|
| บ่ | ไม่ (บ่อิ่ม = ไม่อิ่ม) |
| มะ / ป่ะ / ก่อ / ก๊า / หรอ / เหรอ | ไหม |
| แม่นบ่ / ใช่ก่อ / ไจ่ก่อ | ใช่ไหม |
| ได้บ่ / มีบ่ | ได้ไหม / มีไหม |
| คำถามติดคำหน้าไม่เว้นวรรค | เช่น "29มัย" = "29 ไหม" |
| เสียงยืด/ซ้ำตัวอักษร | ไม่เปลี่ยนความหมาย เช่น "มั้ยยยย" = "มั้ย" |
| คำลงท้ายถิ่นต่อท้ายคำถามอีกชั้น | เจ้ / เด้ / กา, ยังนับเป็นคำถาม |

กฎพรีเช็ค (สำคัญ): ถ้าข้อความมีคำถาม (คำลงท้ายคำถาม/wh/เครื่องหมาย ?) ห้ามตอบข้อ 0 Miscellaneous เด็ดขาด แม้ข้อความจะสั้นมากหรือดูไม่มีบริบทก็ตาม, ให้เลือกเฉพาะข้อ 1 (คำถามเชิงประชด), ข้อ 2 (มีคำขอชัดเจน), หรือข้อ 3 เท่านั้น

## 2. นิยามแต่ละคลาส

### ข้อ 0: Miscellaneous
ไม่มีเนื้อหาให้ตีความเจตนาได้ หรือ เป็นโฆษณาขายของ

- คำทักทาย/คำอุทานล้วนที่ไม่มีคำบอกอารมณ์ | วลีนามลอยๆ ที่ไม่รู้บริบทว่าอ้างถึงอะไร | สะกดจนจับใจความไม่ได้ | โพสต์ซื้อขายสั้นๆ (cf//, ราคา, จอง)
- อีโมจิล้วนที่ไม่สื่ออารมณ์ชัด (🔴 ✅ ธงชาติ), ถ้าสื่ออารมณ์ชัดเจน (😭 😍 😂) ให้ไปข้อ 5 แทน
- โฆษณา = บรรยายสรรพคุณสินค้าเชิงขาย (คำอวยเกินจริง / "ผสานคุณค่า" / "บางเบา" / "ปราศจาก...") ร่วมกับ อย่างน้อยหนึ่งใน: สาขา / เบอร์โทร / ลิงก์ / แฮชแท็กชื่อร้าน-สินค้า / คำชวนซื้อ หรือ บรรยายสรรพคุณต่อเนื่องแบบใบปะหน้าสินค้า (ไม่ใช่ประสบการณ์ใช้จริงของผู้เขียน) → Miscellaneous เสมอ แม้ข้อความจะยาวและดูเหมือนคำแนะนำ (ไม่มีคลาส "Advertisement" แยกต่างหาก)
  - แฮชแท็กข่าว/การเมือง/กีฬา ไม่นับ เป็นแฮชแท็กร้าน, พาดหัวข่าวที่อ้างถึงบุคคล/เหตุการณ์จริง เช่น "คำชี้แจงของ [ชื่อบุคคล]" ยังคงไปข้อ 6 Assertion แม้จะมีแฮชแท็กต่อท้าย
  - มีแค่ชื่อรุ่น + ราคา/สเปกตัวเลขล้วนๆ ไม่มีคำขายของเลย = ข่าวราคา → ข้อ 6 Assertion

ข้อยกเว้น (ใช้ไม่ได้กับกรณีโฆษณา): ถ้ามีคำอารมณ์/คำประเมิน/เสียงยืด/หัวเราะ/อีโมจิอารมณ์ หรือคำอุทานเชิงประชด (แหม/แหม๋/อ้าว/โอ้โห) แม้ข้อความจะสั้นมาก ให้ไล่ข้อ 1-5 ต่อ ไม่ตัดจบที่ข้อนี้ | พาดหัวที่แฮชแท็กเป็นการเยาะเย้ย → ข้อ 1

### ข้อ 1: Sarcasm
มีช่องว่างระหว่าง สิ่งที่พูด กับ สิ่งที่ผู้เขียนคิดจริง (ประชด / เสียดสี / เย้ยหยัน)

ต้องมี ร่องรอยเชิงภาษาที่ชี้ชัดว่าเยาะเย้ย/ประชด ไม่ใช่แค่น้ำเสียงลบหรือวิจารณ์ตรงๆ
และถ้าข้อความมี คำแนะนำตรงตัว (แนะนำ / อย่า...เลย / ...เถอะ / เหอะ / ควร)
ให้ ข้ามไปข้อ 4 ก่อนเสมอ แม้น้ำเสียงจะแรง ดุ หรือมีคำเสียดสีปนอยู่ด้วยก็ตาม

- คำอุทานเปิดประชด: แหม / แหม๋ / อ้าว / โอ้โห / ว้าว + ชี้ความย้อนแย้งของอีกฝ่าย
- "5555" / "ฮ่าๆ" ตามหลังการจับผิดคนอื่น (ต่างจาก 5555 ที่ขำ/เอ็นดูเฉยๆ ซึ่งเป็นข้อ 5 Expression)
- ชม/ขอบคุณแบบไม่จริงใจ (เก่งจริง, ดีจัง, บริการดีมาก) แล้วตามด้วยข้อเท็จจริงตรงข้าม
- เปรียบเทียบสองอย่างผิดที่ผิดทางโดยไม่อธิบาย (เช่น ค่าจอดแพงกว่าค่าอาหาร)
- "ได้แค่นี้" / "แค่นี้เอง" / "ไม่ถึงสักที" / "ดูออก" | "ตลก" / "พิลึก" / "แปลกดี" ตามด้วย ? หรือ ...
- คำถามวาทศิลป์ที่ไม่ต้องการคำตอบจริง: "เพื่อ...?" / "จะเอาอะไรอีก" / "...สินะ" / "จะให้...หรือไง/อ่ะ" / คำถามแสดงความไม่เชื่อหรือรู้คำตอบอยู่แล้ว ("...เลยหรอ" / "จริงหรอ")
  - คำว่า "ขอ"/"ให้" ในคำถามลักษณะนี้ ไม่ใช่คำขอจริง ห้ามจัดเป็น Request
  - แต่ถ้าเป็นคำถามขอความหมายจริงต่อคำพูดของคนอื่น เช่น "หมายถึงอะไรครับที่..." ให้ไปข้อ 3 Question แทน
- อีโมจิเยาะเย้ย/สงสัย (🙄 😏 🤡) ต่อท้ายคำชม → Sarcasm เสมอ แม้ในข้อความเองไม่มีคำเสียดสีเลย
- เหน็บด้วยภาษาถิ่น/คำหยาบ + คำลงท้ายกระแนะกระแหน (เนาะ/น้า)
- พาดหัวกีฬา/การเมือง + แฮชแท็ก จะเป็น Sarcasm ก็ต่อเมื่อมีคำเยาะเย้ยชัดเจนในเนื้อความด้วย (...สักที, เก่งจริง, แหม), แฮชแท็ก + รายงานปัญหาสินค้าเฉยๆ ที่ไม่มีคำเยาะเย้ย ไม่ใช่ Sarcasm → ข้อ 6

ไม่ใช่ Sarcasm: บ่นตรงๆ มีเหตุผลไม่มีน้ำเสียงเย้ยหยัน แม้เนื้อหาจะลบหรือรุนแรง → ข้อ 5 Expression | รายงานสินค้าเสีย/ใช้ไม่ได้โดยไม่เย้ยหยัน → ข้อ 6 Assertion | แก่นคือขอให้ผู้อ่านลงมือทำ → ข้อ 2

### ข้อ 2: Request
ขอให้ผู้อ่านลงมือทำ "เพื่อผู้เขียน"

เข้าข้อนี้ได้ ต่อเมื่อมีคำขอชัดเจนเท่านั้น:
รบกวนช่วย / รบกวนส่ง / รบกวนดำเนินการ | ช่วย...หน่อย/ด้วย | ขอ...หน่อย | ขอทราบ | แนะนำ...ให้หน่อย/ค่ะ
ถ้าไม่มีคำเหล่านี้ ห้ามตอบ Request เด็ดขาด ให้ไล่ข้อ 3-6 ต่อ ต่อให้เนื้อความดูเหมือนอยากให้ใครทำอะไรก็ตาม

"รบกวน" เฉยๆ ไม่พอ, "รบกวนถาม" / "รบกวนสอบถาม" เป็นแค่คำนำก่อนถาม
ไม่ใช่คำขอ → ข้อ 3 Question

- ถามราคา/ส่วนลด/สาขา/วิธีซื้อ/ผ่อน/สเปก กับเพจร้านค้า = ข้อ 3 Question ไม่ใช่ Request
- ขอให้ส่งข้อมูล/ติดต่อกลับ/ตรวจสอบ/แก้ไข/ดำเนินการ → Request
- "แนะนำ...ให้หน่อยค่ะ" = ขอคำแนะนำจากผู้อ่าน → Request (ต่างจากการ *ให้* คำแนะนำ ซึ่งเป็นข้อ 4)
- "จะช่วย.../จะได้ช่วย..." ที่บอกผลดีในอนาคต (บรรยายผลลัพธ์ ไม่ใช่คำสั่ง) → ไม่ใช่ Request
- "อยาก/อยากเห็น" + สิ่งที่อยากให้เกิดขึ้น + คำประเมิน (น่าเกลียด/แย่/สมควร/...เกินไป) = การระบายความคิดเห็น → ข้อ 5 Expression ไม่ใช่ Request
- สั่งหรือชักชวนเพื่อ "ประโยชน์ของผู้อ่านเอง" (อย่า...เลย, ควร..., ...เถอะ) = ข้อ 4 Recommendation ไม่ใช่ Request

### ข้อ 3: Question
ถามเพื่อขอคำตอบ/ข้อมูลจริง (เป็นค่าเริ่มต้นของข้อความที่มีคำถามแต่ไม่เข้าข้อ 1 หรือข้อ 2)

- คำลงท้าย: ไหม มั้ย มะ ป่ะ บ่ ก่อ ก๊า หรอ เหรอ หรือเปล่า ใช่ไหม | wh: อะไร ทำไม ยังไง ที่ไหน เมื่อไหร่ วันไหน เท่าไร กี่ | อยากทราบว่า | ?
- คำถิ่นเขียนติดกันเป็นคำเดียว: ไจ่ก่อ/ใช่ก่อ/แม่นบ่ = ใช่ไหม | ได้บ่/มีบ่/ได้ก่อ = ได้ไหม/มีไหม (มีคำลงท้ายถิ่นต่อท้ายอีกชั้นก็ยังนับเป็นคำถาม)
- การชวน/นัด/เชิญที่เปิดให้ตอบรับ-ปฏิเสธ (ไป...กันมั้ย, ...ป่ะ, ไปกันเนาะ) → Question เสมอ ไม่ใช่ Request เพราะยังเปิดให้ปฏิเสธได้
- ข้อความยาวที่มีคำถามจริงแทรกอยู่ตรงไหนก็ได้ (ต้น/กลาง/ท้ายประโยค) แม้ตามด้วยเนื้อหาบอกข้อมูลยาวแค่ไหนก็ตาม → ยึดประโยคที่ต้องการคำตอบเป็นตัวตัดสินเสมอ

### ข้อ 4: Recommendation
ผู้เขียนแนะนำเอง "เพื่อประโยชน์ของผู้อ่าน" ไม่ใช่ผู้ขาย

- แนะนำ | ลอง...ดู | ควร | น่าจะ...ดีกว่า | ...เถอะ/เหอะ | อย่า...เลย → เข้าข้อนี้แม้น้ำเสียงจะแรง ดุ หรือมีคำหยาบปน
- รีวิวบอกต่อจากผู้ใช้จริง, แต่ถ้าผู้เขียนคือผู้ขาย/แบรนด์เอง (มีสาขา/เบอร์โทร/ลิงก์สั่งซื้อ/แฮชแท็กแบรนด์/คำชวนซื้อ) นั่นคือโฆษณา → ย้อนกลับไปข้อ 0
- ต้องเป็นผู้เขียนแนะนำเอง, เล่าว่า "คนอื่นแนะนำว่า..." หรือคำแนะนำเป็นเพียงส่วนแทรกในบทความที่แก่นคือการให้ข้อมูล → ข้อ 6 Assertion แทน

### ข้อ 5: Expression
อารมณ์ ความรู้สึก ความอยาก ความเห็นส่วนตัว แบบตรงไปตรงมา

- คำอารมณ์ หรือคำประเมิน เป็นแก่นของข้อความ: เศร้า ดีใจ อึดอัด เบื่อ น่ารัก อร่อย น่าเกลียด แย่ ...เกินไป
- อุทาน/เสียงยืด/หัวเราะของผู้เขียนเอง (หู้ววว, 5555, ง่วงจังเลยยย, บ่อิ่ม) | อีโมจิล้วนที่สื่ออารมณ์ชัดเจน (😍 😭 😡 ❤️) แม้ไม่มีตัวอักษรเลย
- "อยาก..." / "อยากเห็น..." / "สนใจ..." / "ผมเชื่อว่า..." = บอกความรู้สึกของตัวเอง ไม่ได้แนะนำหรือสั่งให้คนอื่นทำ
- บ่นอารมณ์ลบพร้อมเหตุผล หรือเล่าประสบการณ์แย่ๆ ของตัวเองด้วยคำหยาบ ("เลิก...แล้ว") โดยไม่มีน้ำเสียงเย้ยหยัน ยังเป็นข้อนี้

ตัวเลือกรองสุดท้าย ห้ามใช้ถ้าเข้าข้อ 1 หรือข้อ 3 ได้ก่อน: มีน้ำเสียงเย้ยหยัน → ข้อ 1 | มีคำถามหรือคำลงท้ายคำถาม → ข้อ 3 | ไม่มีคำอารมณ์หรือคำประเมินใดๆ เลย และแก่นเรื่องคือการเล่าเหตุการณ์/สถานที่/กิจกรรมล้วนๆ (ใคร ทำอะไร ที่ไหน) แม้มีคำเชื่อมยืดเสียงปนอยู่ (แล้ว → แว้ว) → ข้อ 6 Assertion

### ข้อ 6: Assertion
ที่เหลือทั้งหมด: ข้อเท็จจริง ข่าว เหตุการณ์ ข้อมูล ประสบการณ์ รายงานปัญหาสินค้า/สเปก/ราคา

### เตือนซ้ำก่อนตอบ
ถ้าข้อความเป็นโฆษณา/โปรโมชั่นจากผู้ขาย (บรรยายสรรพคุณเชิงขาย + สาขา/เบอร์โทร/ลิงก์/แฮชแท็กร้าน/คำชวนซื้อ) ให้ตอบ Miscellaneous เสมอ แม้จะไล่มาถึงข้อ 4 หรือข้อ 6 แล้วก็ตาม เพราะผู้เขียนคือผู้ขาย ไม่ใช่ผู้ใช้จริงที่มาแนะนำ

## 3. ตัวอย่างอ้างอิง (1-shot examples)
